# Bubble Client

## Назначение

Клиентская часть для взаимодействия с серверной частью мессенджера [Bubble](https://github.com/mongolianpes/Bubble-Messenger-Server).  
Включает в себя TLS, регистрацию, авторизацию, отправку сообщений и другие функции.

## Использование

Все функции возвращают строку:
- При успехе — обычная строка с результатом.
- При ошибке — строка, **начинающаяся с символа `$`**.

**Исключение:**  
`GetAvatar` и `GetFile` возвращают байты. При преобразовании ошибки в строку она также начинается с `$`.

**Информация об устройстве** — строка, содержащая данные об устройстве (имя, константы, версии ПО и т.д.).  
Перед отправкой на сервер **хэшируется** и передаётся в захэшированном виде без шифрования.

В функции всегда передаются строки, за исключением случаев, когда указан другой тип (например, `int` или `[]byte`).

### Функции

**Формат описания:**  
`Название(параметр1, параметр2, ...) → возвращаемое_значение`

---

#### `Reg(логин, имя, пароль, информация_об_устройстве) → секретный_ключ_сессии`

Регистрирует нового пользователя и возвращает секретный ключ сессии.

---

#### `Auth(логин, пароль, информация_об_устройстве) → секретный_ключ_сессии + имя_пользователя`

Авторизует пользователя.  
Возвращает секретный ключ сессии и имя пользователя, разделённые символом перевода строки (`\n`).

---

#### `SearchUser(логин, пароль, информация_об_устройстве, строка_поиска, секретный_ключ, попытка_поиска int) → список_пользователей`

Ищет пользователей по строке поиска.  
Поиск производится только среди логинов пользователей, которых уже целенаправленно искали.

Используйте `@` перед логином в строке поиска, чтобы найти пользователя по точному совпадению. Находит любого пользователя. После такого поиска некоторое время пользователя можно будет найти без точного совпадения.

**Возвращаемый формат:**
```
логин имя
логин2 имя2
логин3 имя3
```

- Каждый пользователь — на новой строке
- Логин и имя разделены пробелом

**Пагинация:**  
Функция возвращает ограниченное количество пользователей за один вызов.  
Чтобы получить следующую порцию результатов — увеличьте параметр `попытка_поиска` на 1.

---

#### `SendMessage(логин_отправителя, пароль_отправителя, логин_получателя, информация_об_устройстве, сообщение, секретный_ключ) → статус`

Отправляет сообщение пользователю.  
Возвращает сообщение об успешной отправке или ошибку.

---

#### `CheckMessages(логин, пароль, информация_об_устройстве, секретный_ключ_сессии) → список_сообщений`

Возвращает часть новых сообщений.  
После использования `DelMessages` вернёт следующую часть новых сообщений.

**Формат возвращаемой строки:**
```
логин_отправителя\текст_сообщения\дата_и_время
логин_отправителя2\текст_сообщения2\дата_и_время2
```

- Сообщения разделены переводом строки (`\n`)
- Данные внутри одного сообщения разделены двойными обратными слэшами (`\\`)

---

#### `DelMessages(логин, пароль, информация_об_устройстве, секретный_ключ_сессии) → статус`

Удаляет сообщения.  
Возвращает сообщение об успешном удалении или ошибку.

---

#### `InitDialog(логин_инициатора, пароль_инициатора, логин_ответчика, информация_об_устройстве, секретный_ключ_сессии) → секретный_ключ_инициатора`

Инициализирует обмен общим секретным ключом для диалога.

- Отправляет специальное сообщение пользователю, с которым начинается обмен.
- Сообщение начинается с `i\`, после чего идёт публичный ключ инициатора.

**Возвращает:** секретный ключ инициатора (или ошибку).

---

#### `AnswerInitDialog(логин_ответчика, пароль_ответчика, логин_инициатора, информация_об_устройстве, публичный_ключ_инициатора, секретный_ключ_сессии) → общий_секретный_ключ\хэш`

Продолжает обмен ключами после получения сообщения через `CheckMessages`.

- Если сообщение начинается с `i\` — значит далее идёт публичный ключ инициатора.
- При согласии на обмен отправляет ответное сообщение, начинающееся с `a\`, после которого идёт публичный ключ ответчика.

**Возвращает:**  
`общий_секретный_ключ\хэш_из_секретного_ключа_и_логина_инициатора`

---

#### `EndInitDialog(секретный_ключ_инициатора, публичный_ключ_ответчика, логин_ответчика) → общий_секрет\хэш_логина`

Завершает обмен общим секретным ключом.

- Секретный ключ инициатора уже получен через `InitDialog`.
- Публичный ключ ответчика нужно взять из сообщения, полученного через `CheckMessages` (сообщение начинается с `a\`).

**Возвращает:**  
`общий_секрет\захэшированный_логин_ответчика`  
(логин ответчика хэшируется через общий секрет)

---

#### `SetAvatar(логин, пароль, информация_об_устройстве, секретный_ключ_сессии, аватар) → статус`

Устанавливает аватар для своего аккаунта.  
Возвращает сообщение об успехе или ошибку.

---

#### `GetAvatar(логин, пароль, логин_для_поиска, информация_об_устройстве, секретный_ключ_сессии) → аватар`

Получает аватар другого пользователя.  
Возвращает байты аватара или ошибку.

---

#### `InitAudioDialog(логин_инициатора, пароль_инициатора, логин_ответчика, информация_об_устройстве, секретный_ключ_сессии) → id_диалога\id_пользователя`

Начинает аудио-диалог с другим пользователем.

- Отправляет специальное сообщение ответчику, начинающееся с `ai\`.
- После `ai\` идут: `id_диалога` и `id_пользователя_в_диалоге`, разделённые через `\`.

**Возвращает:**
```
id_диалога\id_пользователя_в_диалоге
```

---

#### `StopAudioDialog(логин_инициатора, пароль_инициатора, логин_получателя, id_диалога, информация_об_устройстве, секретный_ключ_сессии) → статус`

Останавливает аудио-диалог.

- Отправляет пользователю сообщение, начинающееся с `as\`, после которого идёт ID диалога.

---

#### `AudioDialog(id_диалога, id_пользователя_в_диалоге, общий_секретный_ключ_диалога, аудио_сообщение) → аудио_сообщения`

Отправляет и получает аудиосообщения в рамках аудио-диалога.

**Возвращает:**  
Аудиосообщения в кодировке hex, разделённые переводом строки (`\n`).

---

#### `SendFile(логин, пароль, логин_получателя, имя_файла, информация_об_устройстве, секретный_ключ_сессии, файл) → статус`

Отправляет файл другому пользователю.

- Сохраняет файл в серверном хранилище.
- Отправляет получателю специальное сообщение, начинающееся с `p\`.
- После `p\` идут: имя файла и путь в хранилище, разделённые через `\`.

Возвращает сообщение об успешной отправке или ошибку.

---

#### `GetFile(логин, пароль, путь_в_хранилище, информация_об_устройстве, секретный_ключ_сессии) → файл`

Получает файл, отправленный пользователем.  
Возвращает байты файла или ошибку.

---

#### `DelFile(логин, пароль, путь_в_хранилище, информация_об_устройстве, секретный_ключ_сессии) → статус`

Удаляет файл из серверного хранилища.  
Возвращает сообщение об успехе или ошибку.

## Сборка

Используйте библиотеку [Gomobile](https://pkg.go.dev/golang.org/x/mobile/cmd/gomobile) для сборки под мобильные устройства (Android / iOS).

1. Установите библиотеку.
2. Инициализируйте её в репозитории:
```
gomobile init
```
3. Соберите (например, для Android):
```
gomobile bind -v -androidapi 21 -ldflags='-s -w' ./
```
